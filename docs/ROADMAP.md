# 🗺️ YameYame 로드맵

> 시장 분석(딱플레이, 위꾹라이브, 배프, 오마이민턴) 기반. 차별점은 **체육관 현장 특화 + 오프라인 우선**.

## Phase 1 — MVP (현재)

- [x] 단일 서버 골격 (Express + TS + Socket.io)
- [x] ELO 레이팅 엔진 (단식/복식, 승률 예측, 등급)
- [x] MongoDB 스키마 (Member, Game, Club)
- [x] 실시간 이벤트 (게임 스코어, 채팅, 접속 상태)
- [x] 스마트 대진표 (ELO 균형 매칭)
- [x] 모바일 골격 (체육관 테마 + 4개 화면)
- [ ] 회원/게임 CRUD API
- [ ] 모바일 ↔ 서버 연동 (API 클라이언트)

## Phase 2 — 핵심 차별화

- [ ] 게임 결과 → ELO 자동 반영 파이프라인
- [ ] 개인 성과 대시보드 (승률/레이팅 추이 차트)
- [ ] 리더보드 (전체/월간)
- [ ] 오프라인 우선 (expo-sqlite + 동기화 큐)
- [ ] Band OAuth 로그인 + 회원 동기화

## Phase 3 — 운영 기능

- [ ] 코트 예약
- [ ] 회비 관리 (납부 현황, 정산)
- [ ] 운영진 대시보드 (참석률, 이탈 예측)
- [ ] 업적/배지 게임화

## Phase 4 — 장기 (v2.0)

- [ ] AI 자세 분석 (카메라 기반)
- [ ] 음성 스코어 입력
- [ ] AR 라인 판정 보조

## 우선순위 기준

| 기능 | 가치 | 난이도 | 비고 |
|------|------|--------|------|
| ELO + 대진표 | ⭐⭐⭐⭐⭐ | 중 | 경쟁앱 대비 동등+ 확보 — **완료** |
